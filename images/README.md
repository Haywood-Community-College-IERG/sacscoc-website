# Website Images

This folder contains images used in the SACSCOC Reaffirmation Resource Website.

## Recommended Images to Add

1. `favicon.png` - Site favicon (32x32 or 16x16 pixels)
2. `logo.png` - Institution logo (if permitted, de-identified)
3. `timeline-graphic.png` - Visual representation of the reaffirmation timeline
4. `process-flowchart.png` - Process steps visual aid

## Image Guidelines

- Use institution-neutral graphics where possible
- Ensure accessibility (alt text in all Quarto references)
- Optimize file sizes for web delivery
- Use PNG for graphics with transparency, JPEG for photos
